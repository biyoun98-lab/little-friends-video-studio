# Little Friends Video Studio

A lightweight browser-based planning studio for original, child-friendly short videos.

## Features
- Arabic, English, or bilingual episode briefs
- Editable scene-by-scene storyboard
- Copy-ready narration and visual prompts
- Local browser draft saving and TXT export

## Run
Open `index.html` in a modern browser. No build step or paid API key is required.

## Scope
This starter prepares production materials; it does not render finished videos or publish to social platforms. Actual generation needs a connected provider/editor. Publishing requires explicit account authorization.

## Child-safety defaults
For ages 2–6: gentle themes, simple language, no frightening imagery, dangerous imitation, personal-data requests, or external links in child-facing content.
